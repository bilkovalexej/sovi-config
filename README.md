# Сови — публичная конфигурация

Этот репозиторий содержит только общедоступные настройки приложения «Сови». Исходников приложения, ключей подписи, профилей и результатов детей здесь нет.

Файл: [config.json](config.json).
Прямой адрес для приложения: https://raw.githubusercontent.com/bilkovalexej/sovi-config/main/config.json

GitHub Pages для этого адреса не требуется. Начальная конфигурация не содержит update и не объявляет не опубликованную версию доступной.

При каждом изменении увеличивайте revision. После публикации обновления добавляйте update и сохраняйте историю releases; верхние поля последней версии и её запись в releases должны совпадать. Указывайте только действительно доступные в RuStore версии. Приложение читает файл не чаще раза в сутки и продолжает работать офлайн; изменения не обязаны появляться сразу после сохранения файла.
