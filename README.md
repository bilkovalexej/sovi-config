# Сови — публичная конфигурация

Здесь находятся только общедоступные настройки Сови. Исходники приложения, ключи подписи, профили и результаты детей в этот репозиторий не входят.

## Файлы

- [config.json](config.json) — настройки обычной версии приложения. Пока не содержит объявления об обновлении.
- [config-test.json](config-test.json) — тестовые сведения только для проверочных APK. Номера 999001 и 999002 не означают реальные опубликованные версии.

Приложение получает файлы по прямым HTTPS-адресам:

- https://raw.githubusercontent.com/bilkovalexej/sovi-config/main/config.json
- https://raw.githubusercontent.com/bilkovalexej/sovi-config/main/config-test.json

GitHub Pages для этих адресов не требуется.

## Изменение конфигурации

При каждом изменении увеличивайте revision. Добавляйте в обычный файл сведения об обновлении только после доступности выпуска в RuStore. Сохраняйте историю releases. Верхние поля последней версии и её запись в releases должны совпадать.

Обычная версия проверяет файл не чаще раза в сутки при открытии приложения; постоянного фонового опроса нет. В проверочной версии суточного ограничения нет. CDN GitHub может ненадолго кешировать ответ. Офлайн приложение продолжает работать.

## Проверка на телефоне

1. В проверочной сборке открыть приложение и увидеть тестовую карточку; раскрыть историю.
2. В config-test.json увеличить revision и изменить текст. Заново открыть приложение и дождаться получения файла.
3. Для проверки скрытия заменить тестовый файл на объект schemaVersion=1 и новую revision, без update.
4. Для проверки актуальной версии указать versionCode, равный установленному. Для 0.4.44 это 53. Сведения верхнего выпуска и история должны совпадать.
5. После получения конфигурации открыть приложение без интернета: игра работает, доступна сохранённая конфигурация.

Тестовые номера не переносить в config.json. Кеш тестового файла в APK отделён от кеша обычного.
